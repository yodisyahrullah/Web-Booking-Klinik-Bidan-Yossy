# Web Booking Antrean Klinik Bidan Yossy

Aplikasi web manajemen dan pendaftaran antrean pasien online untuk Klinik Bidan Yossy berbasis Laravel.

## Fitur Utama
- Pendaftaran antrean pasien online dengan nomor otomatis (reset setiap hari).
- Dashboard admin untuk memanggil, melayani, dan menghapus antrean.
- Notifikasi suara panggilan otomatis secara *real-time* di halaman tiket pasien.
- Filter antrean khusus hari ini.
